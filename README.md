# Ноготочки

Учебный сервис записи в студию маникюра и бровей. Реализованы клиентский путь, расчёт свободных слотов, защита от конфликтов и чужих данных, личный кабинет и административное управление.

## Возможности

- регистрация и вход по email, опционально Яндекс OAuth;
- услуги, мастера, недельное расписание и блокировки в базе данных;
- свободные слоты с учётом длительности, занятых интервалов и рабочего времени;
- личный кабинет только с собственными записями;
- админка: перенос, отмена, блокировки, добавление и отключение услуг и мастеров;
- Supabase PostgreSQL в production и SQLite для локальной разработки;
- автоматическая миграция ранней версии базы без удаления данных.

## Локальный запуск

```bash
cp .env.example .env
python app.py
```

Откройте `http://localhost:8000`. Для создания администратора задайте `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Публикация

1. Создайте Supabase PostgreSQL и используйте строку Transaction pooler с `sslmode=require`.
2. Подключите репозиторий к Vercel.
3. Добавьте переменные из `.env.example` в Vercel, не загружая `.env`.
4. Укажите `BASE_URL` равным публичному HTTPS-адресу.
5. Выполните Redeploy. `init_db()` создаст новые таблицы и дополнит старую схему.

В проекте приложены `schema.sql`, миграции и полный паспорт `AGENTS.md`.
